Issue



The Patient Management dialog does not currently display third-party processing information, making it difficult to review vendor workflow status without navigating to other pages.



Users should be able to quickly determine the current processing state of IMEKA, Neuroreader, DuraMap, and other supported vendors directly from the patient dialog.



Expected Behavior



Add a dedicated Third-Party Processing section within the Patient Management dialog.



The section should display relevant third-party workflow information, including:



\- IMEKA status

\- Neuroreader status

\- DuraMap status

\- Sent dates

\- Completion dates (when applicable)

\- Error/Issue indicators

\- Related notes or processing concerns



The information should remain visible regardless of the current workflow page so users can review processing details from a single location.



Future Considerations



If the centralized issue management system is implemented, active vendor issues should also be visible within this section.



Goal



Provide a single location for reviewing patient workflow details and third-party processing status without requiring navigation between multiple pages.
